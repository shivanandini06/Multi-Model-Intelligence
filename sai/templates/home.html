The Architecture

Why fusion is adaptive

Static ensembles average every expert equally, so one overconfident model can veto a correct one. AEGIS · QR instead runs four explicit stages on every scan: a tanh calibration that stops a noisy model from saturating at 1.0, a confidence gate that drops experts below 0.20, an agreement-weighted blend over the survivors, and a noisy-OR channel computed on gate-adjusted excess so a crowd of quiet models can never accumulate into a false alarm. A single near-certain expert (≥ 0.85) triggers a decisive floor the average cannot dilute. Gated experts and a triggered floor are both reported to the analyst — an honest low-coverage verdict beats a false certainty.

The Model Bank

Four experts, four blind spots, zero single points of failure

Each model is deliberately chosen to fail on inputs its peers catch. The architecture's accuracy is a property of the disagreement between them — not of any one of them.

M-01

Visual Forensics Network

A dual-branch CNN + Vision Transformer ensemble trained on printed, screen-rendered and sticker-overlaid symbols. It reads the artifact, never the payload — so a QR that carries a perfectly clean link still gets flagged if the code was physically pasted over a legitimate label.

  • Detects logo-swap and overlay tampering
  • Finds halftone & re-printing residue
  • Blind to shortener & redirect abuse
M-02

Payload Grammar Analyzer

A hybrid rule engine + lightweight classifier over the decoded string. It reasons about intent — credential lures, UPI collect traps, fake lottery and parcel-scam phrasing, obfuscated unicode and punycode — rather than about which characters appear.

  • Intent & social-engineering keyword scoring
  • Unicode, homoglyph and nesting deobfuscation
  • Sees through a single redirect hop
M-03

URL Feature Network

An XGBoost classifier over 40+ lexical and structural features engineered from known phishing corpora: entropy, token count, subdomain depth, digit ratio, brand-token injection, scheme, TLD reputation and path shape.

  • Highest raw precision on novel domains
  • Interpretable feature attributions per verdict
  • Cannot judge physical tampering
M-04

Threat Intelligence Link

A live knowledge-graph resolver joining domain registration age, WHOIS registrant entropy, certificate history, community blocklists and co-occurrence with known malicious infrastructure.

  • Flags 3-day-old domains instantly
  • Expands shorteners to true destination
  • No coverage on isolated private hosts
